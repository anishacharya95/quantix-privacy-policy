# Quantix Privacy Policy

This repository publishes the privacy policy for the Quantix Android application.

**Policy page:** https://anishacharya95.github.io/quantix-privacy-policy/

**Effective date:** November 21, 2026

Quantix is a global market-intelligence app for NEPSE, NSE/BSE, US markets and supported cryptocurrency markets. The policy explains local app storage, external market-data/news providers, network requests, data retention, security and contact options.

The policy is written against the current app implementation and its documented providers. Review and update it whenever app features, SDKs, permissions or providers change.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub will publish the root `index.html` at the policy page URL above after deployment completes.

For Google Play Console, use the published HTTPS page URL after it becomes available.
